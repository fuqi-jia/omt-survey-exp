# 无理最优值非凸实验结果

共九个预先固定的实例、69次正式调用；每次限时120秒、单线程、4GB。三类分别为耦合二次、四次约束和非凸析取。

| 工具 | 正确最优返回 | 说明 |
|---|---:|---|
| Z3 | 9/9 | 9个目标值均为精确表示 |
| OCAC | 9/9 | 9个目标值均为精确表示 |
| Gurobi | 9/9 | 全部达到参考精度 |
| Couenne | 8/9 | C(29,5)报告不可行 |
| OptiMathSAT | 0/9 | 8次超时；A(5)返回3+ε |

IPOPT、SLSQP在前两类各六例上采用两组初值。初值I均到达全局最优值，初值II均到达另一局部最优值。A(5)的两值约为3.10260156、4.83465237；B(3,3)的两值约为−2.00100299、1.35928013。

Couenne在C(29,5)上报告不可行，理论最优值为(3√7+√3)/2。相同NL输入连续三次复跑均重复该状态；附带候选值与原始终止状态分别保留。

逐例小数见[表格源文件](table.tex)，解析参考值见`models/`；完整原始输出、候选向量、精确表达式和核对记录均随运行保存。
